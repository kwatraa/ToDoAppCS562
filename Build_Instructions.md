The instructions here will describe you how to build and run my Todo list web app from the submitted files.


System requirements :
- A desktop or laptop computer
- One of the following operating systems:
  - Windows 10 or later  
  - macOS 11 or later  
  - A recent Linux distribution
- A web browser (eg : I used Google Chrome)



Installing required tools:

 first of all install Node.js and npm as per the information provided on https://nodejs.org 
 - Basically open the browser and go to https://nodejs.org 
 - then Download the LTS version according to your OS
 - Run and install defualt options
 - after it's been installed open terminal or powershell according to your OS, and the check the installation or the version by typing - npm -v and then node -v. if it shows u the version that means you have been successful installing it.



Installing Project Dependencies :

After installing Node.js and extracting the project files, open a terminal or PowerShell inside the project root directory (where `package.json` is located).

Run the command     'npm install'   to install all required dependencies and then this command will automatically install all the required dependencies.


And then to run the app:
npm start

and after the server start please open the browser and navigate to local host (http://localhost:3000).
